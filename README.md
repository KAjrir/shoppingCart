# Shopping Cart

A webshop front-end built with React as part of [The Odin Project](https://www.theodinproject.com/).

🔗 **Live demo:** https://shopping-cart-seven-beryl-96.vercel.app

## Features
- Home, products and shopping cart pages with client-side routing
- Products loaded from the [Fake Store API](https://fakestoreapi.com/)
- Add products, change quantities and remove items
- Error page for unknown routes

## Built with
React, React Router, CSS Modules, Vite — deployed on Vercel

## Usage
```bash
npm install
npm run dev
```

## What I learned
- Setting up nested routes and layouts with React Router
- Sharing cart state between pages
- Scoping styles with CSS Modules
